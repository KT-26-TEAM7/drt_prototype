# 개인정보 동의 기능 구현 공유 (다솔 파트)

인영님이 정리해주신 개인정보 보호 관련 회의록의 "사전 고지 및 동의" 항목 중, **제가 맡은 케어콜 대화 파트가 실제로 처리하는 항목만** 골라서 통화 시작 전 간단 동의 기능을 구현했습니다.

## 적용 범위

이 파트(케어콜 대화)에서 실제로 다루는 개인정보만 대상으로 했습니다.

- 통화 음성 및 STT(음성→텍스트) 변환 결과 수집·이용
- STT·LLM 분석 (Gemini API 등 외부 LLM으로 전송될 수 있음)
- 건강 관련 발화(민감정보) 처리 — 어르신이 몸 상태를 말씀하시면 그 내용도 위 목적으로만 사용

**위치정보, 보호자 대상 이동정보 제공, 차량 배차 관련 동의는 DRT 파트 담당이라 이번 구현에 포함하지 않았습니다.** 두 파트 경계는 한 번 맞춰봐야 할 것 같습니다.

## 동작 방식

- 통화 시작 시 첫인사보다 먼저, 위 3가지 항목을 한 번에 묶은 짧은 안내 + 동의 여부를 여쭙니다 (여러 항목을 따로따로 안 묻고 "간략하게" 한 번에).
- "네/좋아요" 계열 → 동의로 판단, 바로 케어콜 진행
- "아니요/싫어요" 계열 → 거부로 판단, 대화 시작 없이 정중히 마무리
- 애매한 답변은 한 번 더 되묻고, 그래도 애매하면 안전하게 거부로 처리
- 동의 여부·시각을 로그로 남김 (개인정보 성격이라 저장소에는 올리지 않음)

## 코드 위치

- `consent.py` — 동의 안내 문구, 응답 판단, 로그 기록 로직 (공용 모듈)
- `gemini_chat_demo.py` — 통화 시작 전에 위 모듈을 호출하도록 연결 (키보드 입력)

## 다음에 확인이 필요한 부분

- 저장 기간·자동 삭제 기준 (회의록 "개인정보 저장 정책" 항목) — 지금은 로컬 로그 파일에 계속 쌓이기만 함, 삭제 정책 미구현
- 위치정보·보호자 제공 동의는 DRT 파트와 경계/역할 분담 확인 필요
- 실제 서비스에서는 사용자 식별(전화번호/ID) 관련 동의도 필요한데, 지금은 데모 단계라 이 부분은 다루지 않음
